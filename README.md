# 🎤➡️🤟 Speech-to-Sign Language Converter

A full-stack AI application that converts real-time speech into sign language using speech recognition and Natural Language Processing (NLP) to improve accessibility for hearing-impaired users.

---

## ✨ Features

- Real-time speech recognition using an offline engine
- NLP-based text cleaning and sentence normalization
- Word-to-sign language mapping
- Python backend with REST APIs
- React.js frontend for real-time interaction
- Privacy-first design with no data storage

---

## 🏗️ System Architecture

User Speech  
→ Speech Recognition  
→ NLP Processing  
→ Sign Mapping  
→ Flask REST API  
→ React Frontend

## 🔐 Privacy & Security

- No emails, passwords, tokens, or credentials
- No user authentication
- No access to personal system files
- All inputs processed in memory only
